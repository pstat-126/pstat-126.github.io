Objectives

In this lab you will:

  • Explore the Palmer Penguins dataset and visualize relationships between variables
  • Manually calculate the OLS estimates \(\widehat{\beta}_0\) and \(\widehat{\beta}_1\)
  • Manually compute standard deviations, RSS, \(\widehat{\sigma}^2\), and standard errors
  • Fit a simple linear regression model using lm() in R
  • Interpret summary() output and extract key model components

3. Manual OLS Calculation

Recall from Lectures 1 and 2 that the ordinary least squares (OLS) estimators are:

\[\widehat{\beta}_1 = \frac{S_{xy}}{S_{xx}}, \qquad \widehat{\beta}_0 = \bar{y} - \widehat{\beta}_1\bar{x}\]

where

\[S_{xx} = \sum_{i=1}^{n}(x_i - \bar{x})^2, \qquad S_{xy} = \sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})\]

4. Manually Computing Standard Deviations and Standard Errors

From Lecture 4, we estimate the error variance \(\sigma^2\) with:

\[\widehat{\sigma}^2 = \frac{\text{RSS}}{n - 2}, \qquad \text{RSS} = \sum_{i=1}^{n} e_i^2, \qquad e_i = y_i - \widehat{y}_i\]

We divide by \(n - 2\) (not \(n\)) because we lose two degrees of freedom estimating \(\beta_0\) and \(\beta_1\).
