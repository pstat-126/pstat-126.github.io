Learning goals

In this lab, we will work with the Palmer Penguins dataset. Our main goals are:

  1. Distinguish between confidence intervals for the mean response and prediction intervals for new observations.
  2. Compute and visualize CI and PI bands using predict().
  3. Partition variation using the ANOVA table and interpret \(R^2\).
  4. Verify the \(F = t^2\) relationship in simple linear regression.
  5. Check model assumptions using residual plots and QQ-plots.

Fitting the model

We model body mass (body_mass_g) using bill length (bill_length_mm) as the predictor.

reg_fit <- lm(body_mass_g ~ bill_length_mm, data = penguins_lab)
summary(reg_fit)

Confidence and Prediction Intervals

When predicting at a new value \(x^*\), there are two distinct questions:

  • Confidence interval for the mean response: What is the average body mass for all penguins with bill length \(x^*\)? Uncertainty comes only from estimating the regression line.
  • Prediction interval for a new observation: What will the body mass of one new penguin with bill length \(x^*\) be? Uncertainty comes from both the estimated line and irreducible individual noise \(\varepsilon^*\).

The formulas are:

\[\text{CI: } \hat{Y}^* \pm t_{1-\alpha/2,\, n-2}\sqrt{\text{MSE}\!\left(\frac{1}{n} + \frac{(x^* - \bar{X})^2}{S_{xx}}\right)}\]

\[\text{PI: } \hat{Y}^* \pm t_{1-\alpha/2,\, n-2}\sqrt{\text{MSE}\!\left(1 + \frac{1}{n} + \frac{(x^* - \bar{X})^2}{S_{xx}}\right)}\]

The extra \(1\) under the radical in the PI accounts for the irreducible individual noise \(\varepsilon^*\).

Analysis of Variance

ANOVA partitions the total variation in \(Y\) into a component explained by the model and a residual component:

\[\underbrace{\sum_{i=1}^n (Y_i - \bar{Y})^2}_{\text{SST}} = \underbrace{\sum_{i=1}^n (\hat{Y}_i - \bar{Y})^2}_{\text{SSR}} + \underbrace{\sum_{i=1}^n (Y_i - \hat{Y}_i)^2}_{\text{SSE}}\]

anova(reg_fit)

The ANOVA table includes:

  • Df: degrees of freedom (1 for model, \(n - 2\) for residuals)
  • Sum Sq: SSR and SSE
  • Mean Sq: \(\text{MSR} = \text{SSR}/1\), \(\text{MSE} = \text{SSE}/(n-2)\)
  • F value: \(F^* = \text{MSR}/\text{MSE}\)

Under \(H_0: \beta_1 = 0\), \(F^* \sim F_{1,\, n-2}\). We reject \(H_0\) at level \(\alpha\) when \(F^*\) exceeds the critical value \(F_{1-\alpha;\, 1,\, n-2}\), found with qf().

n <- nrow(penguins_lab)
F_crit <- qf(0.95, df1 = 1, df2 = n - 2)
cat("Critical value:", round(F_crit, 4), "\n")

Extracting ANOVA components

SSR    <- anova_tbl[1, "Sum Sq"]

cat("SSR =", round(SSR, 2), " SSE =", round(SSE, 2), " SST =", round(SST, 2), "\n")
cat("MSR =", round(MSR, 2), " MSE =", round(MSE, 2), " F =", round(F_stat, 2), "\n")

Connection between \(F\) and \(t\)

In simple linear regression, \(F^* = (t^*)^2\). The F-test and the two-sided t-test for \(\beta_1 = 0\) always lead to the same conclusion.

t_from_model <- summary(reg_fit)$coefficients["bill_length_mm", "t value"]
cat("t^2 =", round(t_from_model^2, 2), "  F =", round(F_stat, 2), "\n")

Model Diagnostics

All inference (CIs, PIs, F-tests) is only valid if the model assumptions hold. The regression model \(Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i\) with \(\varepsilon_i \stackrel{iid}{\sim} N(0, \sigma^2)\) encodes four assumptions:

  1. Linearity: \(E(Y) = \beta_0 + \beta_1 X\)
  2. Independence: observations are uncorrelated
  3. Equal variance (homoscedasticity): \(\text{Var}(\varepsilon_i) = \sigma^2\) for all \(i\)
  4. Normality: \(\varepsilon_i \sim N(0, \sigma^2)\)

We check these assumptions using residual plots. The key functions are residuals() for the residuals \(e_i = Y_i - \hat{Y}_i\) and fitted() for the fitted values \(\hat{Y}_i\).

Plot 1: Residuals vs. \(X\) (linearity)

Random scatter around zero suggests linearity is met. A curved pattern indicates the true relationship is nonlinear.

plot(penguins_lab$bill_length_mm, residuals(reg_fit),
     xlab = "Bill Length (mm)", ylab = "Residuals",
     main = "Residuals vs X", pch = 16, col = "#003660")
abline(h = 0, lty = 2)

Plot 2: Residuals vs. Fitted Values (equal variance)

Constant vertical spread suggests equal variance. A fan shape — spread increasing or decreasing with fitted values — indicates heteroscedasticity.

plot(fitted(reg_fit), residuals(reg_fit),
     xlab = "Fitted Values", ylab = "Residuals",
     main = "Residuals vs Fitted", pch = 16, col = "#003660")
abline(h = 0, lty = 2)
