Setup

library(lterdatasampler)
library(ggplot2)

1. Data overview

The hbr_maples dataset contains measurements of sugar maple (Acer saccharum) seedlings collected at Hubbard Brook Experimental Forest in New Hampshire during 2003 and 2004. The site is part of the Long Term Ecological Research (LTER) network.

The data come from a classic acid-rain study. Decades of acid rain have depleted calcium from northeastern forest soils, harming sugar maple regeneration. Researchers added calcium to one watershed (W1) and left a second watershed as an untreated reference to study the effect on seedling health.

We focus on three variables:

  • stem_dry_mass: seedling stem dry mass in grams
  • corrected_leaf_area: total leaf area in cm²
  • watershed: which watershed the seedling was sampled in. The two levels are "Reference" (untreated control) and "W1" (calcium-treated).
maples <- na.omit(hbr_maples[, c("stem_dry_mass", "corrected_leaf_area", "watershed")])
head(maples)
summary(maples)
table(maples$watershed)

2. Simple linear regression

We begin by examining the relationship between leaf area and stem dry mass.

Seedlings with more leaf area can photosynthesize more, so we expect larger leaf area to be associated with greater stem mass. The proposed model is

\[ \text{stem\_dry\_mass}_i = \beta_0 + \beta_1 \cdot \text{corrected\_leaf\_area}_i + \varepsilon_i, \quad \varepsilon_i \overset{\text{iid}}{\sim} N(0,\sigma^2). \]

ggplot(maples, aes(x = corrected_leaf_area, y = stem_dry_mass)) +
  geom_point(alpha = 0.6) +
  labs(
    title = "Sugar Maple Seedling: Stem Mass vs Leaf Area",
    x = expression("Corrected Leaf Area" ~ (cm^2)),
    y = "Stem Dry Mass (g)"
  ) +
  theme_minimal()

Why categorical predictors need special treatment

Regression models require numeric inputs. The variable watershed takes string values "Reference" and "W1". We cannot substitute a string into the linear equation. If we assigned numbers arbitrarily (say, Reference \(= 1\), W1 \(= 2\)), those numbers would carry no inherent meaning.

The standard solution is to create dummy variables: binary (0/1) indicators, one for each category level except one.

4. Creating a dummy variable

For a categorical variable with \(k\) levels, we create \(k - 1\) dummy variables. One level is designated the reference category. When all dummies equal 0, the observation belongs to the reference group.

Here \(k = 2\), so we need \(k - 1 = 1\) dummy variable. We choose "Reference" as the reference category and define:

\[ D_{W1} = \begin{cases} 1 & \text{if the seedling is from the W1 watershed} \\ 0 & \text{if the seedling is from the Reference watershed} \end{cases} \]

What the model equation looks like for each group

Substituting the dummy values for each group shows that this model fits a separate intercept for each watershed while sharing one slope for leaf area.

Reference watershed (\(D_{W1} = 0\)): \[ E[\text{stem\_dry\_mass}] = \beta_0 + \beta_1 \cdot \text{corrected\_leaf\_area}. \]

W1 watershed (\(D_{W1} = 1\)): \[ E[\text{stem\_dry\_mass}] = (\beta_0 + \beta_2) + \beta_1 \cdot \text{corrected\_leaf\_area}. \]
