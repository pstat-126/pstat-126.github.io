Objectives

In this lab you will:

  • Compare the MLE and OLS estimates of \(\sigma^2\) and explain why MLE is biased
  • Visualize the \(t\)-distribution and use qt() to find critical values
  • Construct confidence intervals for \(\beta_0\) and \(\beta_1\) manually and with confint()
  • Conduct two-sided and one-sided hypothesis tests for regression coefficients
  • Extract and interpret \(t\)-statistics from summary() output

3. MLE vs. OLS Estimate of \(\sigma^2\) (Lec 05)

From Lecture 5, the two estimates of the error variance are:

\[\widehat{\sigma}^2_{\text{OLS}} = \frac{\text{RSS}}{n - 2} = \text{MSE} \qquad \text{(unbiased)}\]

\[\widehat{\sigma}^2_{\text{MLE}} = \frac{\text{RSS}}{n} \qquad \text{(biased — does not correct for the two estimated parameters)}\]

Compute both estimates and display them side by side. Notice which estimate is larger and whether this matches the direction of bias described above.

sigma2_OLS <- RSS / (n - 2)
sigma2_MLE <- RSS / n

data.frame(
  Estimator = c("OLS (unbiased)", "MLE (biased)"),
  Formula   = c("RSS / (n - 2)", "RSS / n"),
  Value     = round(c(sigma2_OLS, sigma2_MLE), 3)
) |>
  kable(align = "llr", caption = "Comparing OLS and MLE estimates of σ²")

4. The \(t\)-Distribution and Critical Values (Lec 05/06)

From Lecture 5, if \(Z \sim N(0,1)\) and \(V \sim \chi^2_k\) independently, then

\[T = \frac{Z}{\sqrt{V / k}} \sim t_k\]

In regression, replacing the unknown \(\sigma^2\) with MSE produces exactly this structure:

\[\frac{\widehat{\beta}_1 - \beta_1}{(\text{MSE}/S_{xx})^{1/2}} \sim t_{n-2}\]

5. Confidence Intervals for \(\beta_1\) and \(\beta_0\) (Lec 06)

From Lecture 6, the \(100(1-\alpha)\%\) confidence intervals are:

\[\widehat{\beta}_1 \pm t_{1-\alpha/2,\, n-2} \cdot \text{SE}(\widehat{\beta}_1), \qquad \text{SE}(\widehat{\beta}_1) = \left(\frac{\text{MSE}}{S_{xx}}\right)^{1/2}\]

\[\widehat{\beta}_0 \pm t_{1-\alpha/2,\, n-2} \cdot \text{SE}(\widehat{\beta}_0), \qquad \text{SE}(\widehat{\beta}_0) = \left[\text{MSE}\!\left(\frac{1}{n} + \frac{\bar{x}^2}{S_{xx}}\right)\right]^{1/2}\]

6. Hypothesis Testing (Lec 06)

For each test below: (1) compute the test statistic \(t^*\), (2) find the critical value using qt(), and (3) compare them to make your decision. We reject \(H_0\) when \(|t^*|\) exceeds the critical value (two-sided) or \(t^*\) falls past the one-sided cutoff.

6.1 Two-Sided Test: \(H_0: \beta_1 = 0\)

The test statistic from Lecture 6 is:

\[t^* = \frac{\widehat{\beta}_1 - 0}{\text{SE}(\widehat{\beta}_1)} \sim t_{n-2} \quad \text{under } H_0\]

# TODO: replace NULL with test statistic
t_star_b1 <- NULL

# Two-sided critical value at alpha = 0.05
t_crit_two <- qt(0.975, df = n - 2)

cat("Test statistic t*   =", round(t_star_b1, 4), "\n")
cat("Critical value ±t*  =", round(t_crit_two, 4), "\n")
cat("Reject H0?", abs(t_star_b1) > t_crit_two, "\n")

6.3 One-Sided Test: \(H_1: \beta_1 < 0\)

A car engineer argues that heavier cars always have lower fuel efficiency. Test this directional claim:

\[H_0: \beta_1 = 0 \quad \text{vs.} \quad H_1: \beta_1 < 0\]

We reject \(H_0\) at level \(\alpha\) when \(t^* < -t_{1-\alpha,\, n-2}\).

Notice that the critical value shifts because all of \(\alpha\) is placed in one tail instead of being split between two.

# TODO: replace NULL with critical value
t_crit_left <- NULL

cat("Test statistic t*   =", round(t_star_b1, 4), "\n")
cat("Critical value      =", round(t_crit_left, 4), "\n")
cat("Reject H0?", t_star_b1 < t_crit_left, "\n")
