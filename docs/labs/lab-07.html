Learning goals

In this lab we conduct a complete multiple linear regression analysis of air quality data. By the end of the lab you will be able to:

  1. Perform exploratory data analysis on a multivariate dataset.
  2. Fit a multiple linear regression model in R and read the full summary() output.
  3. Interpret each regression coefficient as a partial effect.
  4. Build the ANOVA table, perform the overall \(F\)-test, and compute \(R^2\) and adjusted \(R^2\).
  5. Conduct \(t\)-tests and construct confidence intervals for individual coefficients.
  6. Distinguish a confidence interval for the mean response from a prediction interval for a new observation, and compute both using predict().
  7. Check all four regression assumptions with residual plots and identify any violations.
  8. Apply a response transformation and evaluate whether it improves the model.

The Data

The built-in R dataset airquality contains 153 daily air quality measurements collected in New York from May through September 1973. We will model ozone concentration as a function of three meteorological variables.

Variable Description Units
Ozone Mean ozone concentration Parts per billion (ppb)

Wind Average wind speed Miles per hour (mph)
Solar.R Solar radiation Langleys (lang)

Part 2: Fitting the Multiple Regression Model

2.1 Fitting with lm()

We model ozone as a linear function of temperature, wind, and solar radiation:

\[\text{Ozone}_i = \beta_0 + \beta_1 \cdot \text{Temp}_i + \beta_2 \cdot \text{Wind}_i + \beta_3 \cdot \text{Solar.R}_i + \varepsilon_i, \quad \varepsilon_i \overset{\text{iid}}{\sim} N(0, \sigma^2).\]

fit <- lm(Ozone ~ Temp + Wind + Solar.R, data = aq)
summary(fit)

Part 3: ANOVA Table and Model Fit

3.1 Extracting the ANOVA table

The anova() function in R returns the sequential sum of squares for each predictor, along with the residual sum of squares.

anova(fit)

To obtain the full ANOVA table in the standard form (Regression | Error | Total), we can compute the quantities manually from summary(fit).

n  <- nrow(aq)
p  <- length(coef(fit))      # number of estimated parameters (intercept + 3 slopes)

SSE  <- sum(residuals(fit)^2)
SSTO <- sum((aq$Ozone - mean(aq$Ozone))^2)
SSR  <- SSTO - SSE

MSR  <- SSR  / (p - 1)
MSE  <- SSE  / (n - p)
Fstar <- MSR / MSE

cat("SSR  =", round(SSR,  2), " df =", p - 1, "\n")
cat("SSE  =", round(SSE,  2), " df =", n - p,  "\n")
cat("SSTO =", round(SSTO, 2), " df =", n - 1,  "\n")
cat("MSR  =", round(MSR,  2), "\n")
cat("MSE  =", round(MSE,  2), "\n")
cat("F*   =", round(Fstar, 2), "\n")

3.2 The overall \(F\)-test

The overall \(F\)-test asks whether any of the three predictors has a linear relationship with ozone:

\[H_0: \beta_1 = \beta_2 = \beta_3 = 0 \qquad H_a: \text{at least one } \beta_k \neq 0\]

The critical value at \(\alpha = 0.05\) can be computed in R:

qf(0.95, df1 = p - 1, df2 = n - p)

3.3 \(R^2\) and adjusted \(R^2\)

R2     <- SSR / SSTO
R2_adj <- 1 - (SSE / (n - p)) / (SSTO / (n - 1))

Part 6: Residual Diagnostics

We now check whether the four regression assumptions hold.

6.1 Residual plots

For multiple regression, we create a separate residuals vs. \(X_k\) plot for each predictor, plus a residuals vs. fitted plot and a QQ-plot.

par(mfrow = c(2, 3), mar = c(4, 4, 2.5, 1))

plot(aq$Temp,    residuals(fit),
     xlab = "Temp (°F)",      ylab = "Residuals",
     main = "Residuals vs Temp",    pch = 16, col = "steelblue")
abline(h = 0, lty = 2, col = "gray50")

plot(aq$Wind,    residuals(fit),
     xlab = "Wind (mph)",     ylab = "Residuals",
     main = "Residuals vs Wind",    pch = 16, col = "steelblue")
abline(h = 0, lty = 2, col = "gray50")

plot(aq$Solar.R, residuals(fit),
     xlab = "Solar.R (lang)", ylab = "Residuals",
     main = "Residuals vs Solar.R", pch = 16, col = "steelblue")
abline(h = 0, lty = 2, col = "gray50")

plot(fitted(fit), residuals(fit),
     xlab = "Fitted values",  ylab = "Residuals",
     main = "Residuals vs Fitted",  pch = 16, col = "steelblue")

qqnorm(residuals(fit), main = "Normal QQ-Plot", pch = 16, col = "steelblue")

Part 7: Applying a Transformation

The residual plots from Part 6 often reveal problems for the raw ozone model. Because ozone concentrations are bounded below by zero and tend to be right-skewed, a log transformation of the response is a natural remedy.

7.1 Fitting the log-transformed model

fit_log <- lm(log(Ozone) ~ Temp + Wind + Solar.R, data = aq)
summary(fit_log)

7.2 Residual diagnostics for the log model

par(mfrow = c(2, 3), mar = c(4, 4, 2.5, 1))

plot(aq$Temp,    residuals(fit_log),
     xlab = "Temp (°F)",      ylab = "Residuals",
     main = "Residuals vs Temp",    pch = 16, col = "darkorange")
abline(h = 0, lty = 2, col = "gray50")

plot(aq$Wind,    residuals(fit_log),
     xlab = "Wind (mph)",     ylab = "Residuals",
     main = "Residuals vs Wind",    pch = 16, col = "darkorange")
abline(h = 0, lty = 2, col = "gray50")

plot(aq$Solar.R, residuals(fit_log),
     xlab = "Solar.R (lang)", ylab = "Residuals",
     main = "Residuals vs Solar.R", pch = 16, col = "darkorange")
abline(h = 0, lty = 2, col = "gray50")

plot(fitted(fit_log), residuals(fit_log),
     xlab = "Fitted values",  ylab = "Residuals",

7.4 Interpreting coefficients on the log scale

When the response is \(\log(\text{Ozone})\), the fitted equation is:

\[\widehat{\log(\text{Ozone})} = b_0 + b_1 \cdot \text{Temp} + b_2 \cdot \text{Wind} + b_3 \cdot \text{Solar.R}\]

A one-unit increase in \(\text{Temp}\) is associated with a \(b_1\)-unit increase in \(\log(\text{Ozone})\), which corresponds to a multiplicative change of \(e^{b_1}\) in ozone on the original scale.

exp(coef(fit_log))
