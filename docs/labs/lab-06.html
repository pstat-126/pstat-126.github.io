Part 1: Matrix Operations in R

Before we can work with regression in matrix form, we need to be comfortable with a few basic operations: construction, multiplication, transpose, and inverse.

1.1 Creating and indexing matrices

The matrix() function arranges a vector of values into rows and columns. By default R fills by column; setting byrow = TRUE fills by row, which is usually more readable when you are typing in the values directly.

A <- matrix(c(1, 2, 3,
              1, 4, 5,
              1, 6, 7,
              1, 8, 9),
            nrow = 4, ncol = 3, byrow = TRUE)

A          # print the matrix
dim(A)     # (rows, columns)
A[2, 3]   # element in row 2, column 3

Notice that the first column of \(A\) is all 1s. This pattern will come up again when we build the design matrix for regression. The column of 1s accounts for the intercept.

1.2 Matrix multiplication

For the product \(AB\) to be defined, the number of columns in \(A\) must equal the number of rows in \(B\). The result has as many rows as \(A\) and as many columns as \(B\).

Suppose \[ B = \begin{pmatrix} 2 & 3 \\ 5 & 7 \\ 6 & 1 \end{pmatrix}. \]

1.3 Transpose and inverse

The transpose of a matrix flips rows and columns. If \(A\) is \(n \times m\), then \(A^T\) is \(m \times n\).

The inverse of a square matrix \(M\) is the matrix \(M^{-1}\) such that \(MM^{-1} = I\), where \(I\) is the identity matrix. In R, solve(M) computes \(M^{-1}\). Not every square matrix has an inverse. A matrix is invertible only if it has full rank.

M <- matrix(c(1, 1,
              1, 0),
            nrow = 2, byrow = TRUE)

M_inv <- solve(M)
M_inv

M %*% M_inv   # should be the 2x2 identity matrix

These three operations (matrix multiplication, transpose, and inverse) are all we need to derive the OLS estimator.

Part 2: Multiple Linear Regression via Matrices

2.1 The model

A multiple linear regression model with \(p\) predictors and \(n\) observations can be written as \[\mathbf{y} = X\boldsymbol{\beta} + \boldsymbol{\varepsilon},\] where each piece has a specific role:

Symbol Dimension Meaning
\(\mathbf{y}\) \(n \times 1\) observed responses
\(X\) \(n \times (p+1)\) design matrix (first column all 1s)
\(\boldsymbol{\beta}\) \((p+1) \times 1\) unknown coefficients \((\beta_0, \beta_1, \ldots, \beta_p)^T\)
\(\boldsymbol{\varepsilon}\) \(n \times 1\) unobserved errors

The goal is to estimate \(\boldsymbol{\beta}\). Ordinary least squares (OLS) finds the \(\boldsymbol{\beta}\) that minimizes the total squared error \(\|\mathbf{y} - X\boldsymbol{\beta}\|^2\). Taking the derivative and setting it to zero yields the normal equations, whose solution is: \[\hat{\boldsymbol{\beta}} = (X^TX)^{-1}X^T\mathbf{y}.\]

This is the formula we will compute step by step.

2.4 Computing \(\hat{\boldsymbol{\beta}}\) step by step

We now compute the OLS estimate \(\hat{\boldsymbol{\beta}} = (X^TX)^{-1}X^T\mathbf{y}\) using the matrix operations from Part 1.

It helps to break the formula into pieces:

  1. Compute \(X^TX\) — a \((p+1)\times(p+1)\) matrix summarizing how the predictors relate to each other.
  2. Invert it to get \((X^TX)^{-1}\).
  3. Compute \(X^T\mathbf{y}\) — a \((p+1)\times 1\) vector summarizing how each predictor relates to the response.
  4. Multiply to get \(\hat{\boldsymbol{\beta}}\).
