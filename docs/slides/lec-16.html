Extra Sum of Squares

The Extra Sum of Squares — Definition

When more terms are added to a regression model, SSR always increases and SSE always decreases while SSTO remains unchanged.

The amount of increase (reduction) in SSR (SSE) is the extra sum of squares. It measures the contribution of the added terms to the regression model, given other terms are already in the model.

Comparing a full model \(F\) to a restricted model \(R\) (where \(R\) is nested in \(F\)):

  • \(SSE(R)\) is always larger than \(SSE(F)\)
  • Because SSTO is fixed, the extra SS can be written either way:

\[\underbrace{SSR(F) - SSR(R)}_{\text{extra SS}} = SSE(R) - SSE(F)\]

The Extra Sum of Squares — F Test

To test whether the added predictors contribute significantly, use the F statistic:

\[F^* = \frac{(SSE(R) - SSE(F))\,/\,(df_R - df_F)}{SSE(F)\,/\,df_F} \overset{H_0}{\sim} F_{df_R - df_F,\; df_F}\]

where \(df_F\) and \(df_R\) are degrees of freedom associated with \(SSE(F)\) and \(SSE(R)\).

Reject \(H_0\) if \(F^* > F(1 - \alpha;\; df_R - df_F,\; df_F)\).

The \(t\)-tests in summary() are special cases: for a single predictor, \(F^* = (t^*)^2\).

Practice: Extra SS F Test

Using mtcars, two models are fit:

  • Restricted model \(R\): mpg ~ wt — \(SSE(R) = 278.32\), \(df_R = 30\)
  • Full model \(F\): mpg ~ wt + hp + qsec — \(SSE(F) = 186.06\), \(df_F = 28\)

(a) What is the extra sum of squares? What does it represent?

(b) Compute the F statistic \(F^*\).

(c) The critical value is \(F(0.95;\, 2,\, 28) = 3.34\). What do you conclude at \(\alpha = 0.05\)?

Practice: Solution

(a) Extra SS \(= SSE(R) - SSE(F) = 278.32 - 186.06 = 92.26\)

This is \(SSR(\texttt{hp}, \texttt{qsec} \mid \texttt{wt})\) — the additional variation in mpg explained by hp and qsec, given wt is already in the model.

(b)

\[F^* = \frac{(278.32 - 186.06)\,/\,(30 - 28)}{186.06\,/\,28} = \frac{92.26\,/\,2}{186.06\,/\,28} = \frac{46.13}{6.645} = 6.94\]

(c) Since \(F^* = 6.94 > 3.34 = F(0.95;\, 2,\, 28)\), we reject \(H_0\). There is significant evidence that hp and qsec together contribute to the model, given wt is already included (\(p = 0.004\)).

Sequential Sum of Squares (Type I) — Setup

Consider the full model \(Y_i = \beta_0 + \beta_1 X_{i1} + \beta_2 X_{i2} + \beta_3 X_{i3} + \varepsilon_i\). We introduce sequential SS by fitting three nested models:

\[\text{Model 1: } Y_i = \beta_0 + \beta_1 X_{i1} + \varepsilon_i\] \[\text{Model 2: } Y_i = \beta_0 + \beta_1 X_{i1} + \beta_2 X_{i2} + \varepsilon_i\] \[\text{Model 3: } Y_i = \beta_0 + \beta_1 X_{i1} + \beta_2 X_{i2} + \beta_3 X_{i3} + \varepsilon_i\]

Let \(SSR(X_1)\), \(SSR(X_1, X_2)\), \(SSR(X_1, X_2, X_3)\) be the regression SS and \(SSE(X_1)\), \(SSE(X_1, X_2)\), \(SSE(X_1, X_2, X_3)\) be the error SS for Models 1, 2, and 3. Define:

\[SSR(X_2 \mid X_1) = SSR(X_1, X_2) - SSR(X_1) = SSE(X_1) - SSE(X_1, X_2)\] \[SSR(X_3 \mid X_1, X_2) = SSR(X_1, X_2, X_3) - SSR(X_1, X_2) = SSE(X_1, X_2) - SSE(X_1, X_2, X_3)\]

Sequential Sum of Squares (Type I) — SSTO Decomposition

Fitting the full model (Model 3), SSTO decomposes as:

\[SSTO = SSR(X_1) + SSR(X_2 \mid X_1) + SSR(X_3 \mid X_1, X_2) + SSE(X_1, X_2, X_3)\]

Each term has a clear interpretation:

  • \(SSR(X_1)\): SS explained by \(X_1\) alone
  • \(SSR(X_2 \mid X_1)\): extra SS due to adding \(X_2\) to the model that already includes \(X_1\)
  • \(SSR(X_3 \mid X_1, X_2)\): extra SS due to adding \(X_3\) to the model that already includes \(X_1\) and \(X_2\)

Type I SS depends on the order in which variables are entered into the model. In R, anova() gives Type I SS.

Partial Sum of Squares (Type III) — Motivation

For the full model \(Y_i = \beta_0 + \beta_1 X_{i1} + \beta_2 X_{i2} + \beta_3 X_{i3} + \varepsilon_i\), to test \(H_0: \beta_1 = 0\) we compare:

  • Full model \(F\): includes \(X_1, X_2, X_3\)
  • Restricted model \(R\): drops \(X_1\), includes only \(X_2, X_3\)

The extra SS is \(SSR(X_1 \mid X_2, X_3) = SSE(R) - SSE(F)\) — the SS explained by \(X_1\) given \(X_2\) and \(X_3\) are already in the model.

Similarly:

  • To test \(H_0: \beta_2 = 0\), compare full model to model with \(X_1, X_3\) only \(\rightarrow\) gives \(SSR(X_2 \mid X_1, X_3)\)
  • To test \(H_0: \beta_3 = 0\), compare full model to model with \(X_1, X_2\) only \(\rightarrow\) gives \(SSR(X_3 \mid X_1, X_2)\)

One can calculate these by fitting multiple reduced models. The partial (Type III) sum of squares computes them simultaneously.

Partial Sum of Squares (Type III) — via anova()

We can verify any partial SS by explicitly comparing the full and reduced models. To test \(H_0: \beta_{hp} = 0\):

fit_no_hp <- lm(mpg ~ wt + qsec, data = mtcars)   # restricted model
anova(fit_no_hp, fit3)                              # extra SS = SSR(hp | wt, qsec)

Partial Sum of Squares (Type III) — Table & Properties

Source SS \(H_0\) tested
\(X_1\) \(SSR(X_1 \mid X_2, X_3)\) \(\beta_1 = 0\) given \(X_2, X_3\) in model
\(X_2\) \(SSR(X_2 \mid X_1, X_3)\) \(\beta_2 = 0\) given \(X_1, X_3\) in model
\(X_3\) \(SSR(X_3 \mid X_1, X_2)\) \(\beta_3 = 0\) given \(X_1, X_2\) in model

Key properties:

  • Order does not matter — each SS is always conditioned on all other predictors, regardless of how they appear in lm()
  • These SS do not add up to \(SSR(X_1, X_2, X_3)\) — unlike Type I SS
  • Each partial SS and F-test is equivalent to the corresponding \(t\)-test in summary()

When the question is “does \(X_k\) belong in the model, given everything else is already included?” — always use partial (Type III) SS.

Practice: Sequential vs. Partial SS

Using fit3 <- lm(mpg ~ hp + wt + qsec, data = mtcars):

(a) The sequential SS for wt is 252.6 (from anova(fit1, fit2, fit3)). The partial SS for wt is 183.1 (from Anova(fit3, type="III")). Why is the sequential SS larger?

(b) For testing \(H_0: \beta_{wt} = 0\) given hp and qsec are in the model, should you use sequential or partial SS? Why?

(c) True or false: changing the order of predictors in lm(mpg ~ wt + hp + qsec) changes the Type III \(p\)-values.

Practice: Solution

(a) The sequential SS for wt conditions only on hp being in the model. It measures the extra contribution of wt after just hp. The partial SS conditions on both hp and qsec, leaving less variation for wt to explain.

(b) Use partial (Type III) SS. The null hypothesis \(H_0: \beta_{wt} = 0\) tests whether wt contributes given hp and qsec are both in the model — exactly what partial SS measures.

(c) False. Type III SS are adjusted for all other predictors regardless of the order they appear in the formula. Reordering predictors in lm() does not change partial SS or \(p\)-values.

Variable Selection

Why Variable Selection?

  • In practice, many candidate predictors are measured but not all contribute meaningfully
  • Smaller models produce more precise inference and are easier to interpret
  • With \(p - 1\) candidate predictors, there are \(2^{p-1}\) possible models — we need a systematic approach

Occam’s razor: the model that fits observations sufficiently well in the least complex way should be preferred. We need criteria that balance goodness of fit against model complexity.

Why Not SSE or \(R^2\)?

Both SSE and \(R^2\) are flawed as sole selection criteria:

  • SSE always decreases when predictors are added → always selects the largest model
  • \(R^2\) always increases when predictors are added → same problem

Adjusted \(R^2\) penalizes for extra parameters:

\[R^2_{\text{adj}} = 1 - \frac{SSE/(n-p)}{SSTO/(n-1)}\]

It can decrease when an unhelpful predictor is added, but has no direct probabilistic interpretation.

We need criteria with formal statistical justification. AIC, BIC, and Mallow’s \(C_p\) can give us this.

AIC and BIC

AIC and BIC are model comparison criteria. They are numbers you compute for a fitted model that balance fit against complexity. They are not selection procedures themselves; they are the metrics that selection procedures use.

  • As a criterion: compute AIC (or BIC) for any fitted model (lower is better)
  • As the basis for selection: compare values across candidate models and pick the smallest;

Both take the form: goodness-of-fit term + complexity penalty. Adding a useless predictor reduces the fit term only slightly but increases the penalty, so the total goes up.

AIC and BIC — Formulas

AIC (Akaike Information Criterion) — based on information theory; estimates out-of-sample prediction error; penalizes each parameter by 2.

\[\text{AIC} = n \log\!\left(\frac{SSE}{n}\right) + 2p\]

BIC (Bayesian Information Criterion) — derived from a Bayesian perspective; heavier penalty than AIC when \(n > 7\), favoring smaller models.

\[\text{BIC} = n \log\!\left(\frac{SSE}{n}\right) + \log(n) \cdot p\]

Select the model with the smallest AIC (or BIC).

Criterion Penalty Tendency
AIC \(2p\) Favors slightly larger models
BIC \(\log(n)\cdot p\) Favors smaller models

Mallow’s \(C_p\)

An unbiased estimate of normalized total mean squared prediction error:

\[C_p = \frac{SSE}{\hat{\sigma}^2} + 2p - n\]

where \(\hat{\sigma}^2 = MSE\) is estimated from the full model (all candidate predictors).

When the model is unbiased, \(E(C_p) \approx p\).

How to use \(C_p\):

  1. Plot \(C_p\) vs. \(p\) along with the line \(C_p = p\)
  2. Points near the line → adequate fit, low bias
  3. Points far above the line → model is underfitting
  4. Among models near the line, prefer smaller \(p\)

Stepwise Procedures

With \(p - 1\) candidate predictors, there are \(2^{p-1}\) possible models. For large \(p\), we can use stepwise methods to select predictors for our model. Stepwise methods are greedy approximations that search the model space one predictor at a time.

All stepwise methods use AIC as the decision criterion at each step (or BIC if k = log(n)). There are three strategies:

Method Starting point Move at each step
Backward elimination Full model Remove the predictor that most lowers AIC
Forward addition Intercept only Add the predictor that most lowers AIC

Stepwise procedures are greedy. They make the locally best move at each step and are not guaranteed to find the globally best model.

Backward Elimination

Start with the full model. At each step, remove the predictor whose removal most lowers AIC. Stop when removing anything would increase AIC.

In R:

(fit_back <- step(full_model, direction = "backward"))

Forward Addition

Start with the intercept-only model. At each step, add the predictor whose addition most lowers AIC. Stop when adding anything would increase AIC.

In R:

(fit_fwd <- step(lm(mpg ~ 1, data = mtcars), scope = formula(full_model), direction = "forward"))

The scope argument tells step() the largest model it is allowed to consider.
