ANOVA Decomposition

Review: ANOVA in SLR

In SLR, total variation in \(Y\) splits cleanly into two parts:

\[\underbrace{\sum_{i=1}^n (Y_i - \bar{Y})^2}_{\text{SSTO}} = \underbrace{\sum_{i=1}^n (\hat{Y}_i - \bar{Y})^2}_{\text{SSR}} + \underbrace{\sum_{i=1}^n (Y_i - \hat{Y}_i)^2}_{\text{SSE}}\]

Source df SS MS \(F^*\)
Regression \(1\) SSR MSR MSR/MSE
Error \(n - 2\) SSE MSE
Total \(n - 1\) SSTO

Everything generalizes to multiple regression. The sums of squares are identical in definition. Only the degrees of freedom change.

ANOVA Decomposition in Multiple Regression

Total variation in \(Y\) always splits as: \(\quad \text{SSTO} = \text{SSR} + \text{SSE}\)

SSTO (Total Sum of Squares) — total variability in \(Y\) around \(\bar{Y}\); computed from data alone, independent of the model

\[\text{SSTO} = \textstyle\sum_{i=1}^n (Y_i - \bar{Y})^2\]

SSR (Regression Sum of Squares) — variation the fitted model explains; how far each \(\hat{Y}_i\) moves away from \(\bar{Y}\)

\[\text{SSR} = \textstyle\sum_{i=1}^n (\hat{Y}_i - \bar{Y})^2\]

SSE (Error Sum of Squares) — leftover variation the model cannot explain; sum of squared residuals

\[\text{SSE} = \textstyle\sum_{i=1}^n (Y_i - \hat{Y}_i)^2 = \mathbf{e}^T\mathbf{e}\]

Degrees of Freedom

Source df Intuition
Regression \(p - 1\) One df per predictor (\(p - 1\) slopes to estimate)
Error \(n - p\) \(n\) observations \(-\) \(p\) parameters estimated (\(\beta_0, \beta_1, \ldots, \beta_{p-1}\))
Total \(n - 1\) \(n\) observations \(-\) 1 (the grand mean \(\bar{Y}\))

Key change from SLR: In SLR, \(p = 2\) (intercept + one slope), so \(\text{df}(\text{SSE}) = n - 2\). In multiple regression, each additional predictor costs one degree of freedom from the error.

Why Error df Matters

Going back to the salary example: Model 1 has 28 error df, Model 2 has 26.

MSE \(= \text{SSE}/(n-p)\) uses error df as its denominator. Fewer df means \(\sigma^2\) is estimated from less information. That uncertainty effects everything that depends on it: standard errors, \(t\)-tests, and confidence intervals.

Concretely, \(t\)-critical values get larger as error df decreases:

Error df \(t_{0.025}\) What it means
28 (Model 1) 2.048 narrower CIs, easier to reject \(H_0\)
26 (Model 2) 2.056 slightly wider
10 2.228 noticeably wider
5 2.571 much wider (cost of small \(n\) or large \(p\))

The ANOVA Table for Multiple Regression

Source df SS MS \(F^*\)
Regression \(p - 1\) SSR \(\text{MSR} = \dfrac{\text{SSR}}{p-1}\) \(\dfrac{\text{MSR}}{\text{MSE}}\)
Error \(n - p\) SSE \(\text{MSE} = \dfrac{\text{SSE}}{n-p}\)
Total \(n - 1\) SSTO

Two key quantities from the table:

  • \(\text{MSE} = \dfrac{\text{SSE}}{n - p}\) — unbiased estimator of \(\sigma^2\) (same role as in SLR, but now divided by \(n-p\))
  • \(F^* = \dfrac{\text{MSR}}{\text{MSE}}\) — test statistic for overall regression significance

Estimating \(\sigma^2\)

Result: Under the model assumptions, \(E(\text{MSE}) = \sigma^2\).

So \(\text{MSE} = \dfrac{\text{SSE}}{n - p}\) is an unbiased estimator of \(\sigma^2\), and:

\[\hat{\sigma} = \sqrt{\text{MSE}}\]

is the residual standard error. This is the typical distance between an observed \(Y_i\) and the fitted regression surface.

In R’s summary() output, this appears as “Residual standard error: X on Y degrees of freedom” — where X \(= \hat\sigma\) and Y \(= n - p\).

The F-Test for Overall Significance

The F-Statistic

The overall F-test asks: does this collection of predictors explain any variation in \(Y\) at all?

\[H_0: \beta_1 = \cdots = \beta_{p-1} = 0 \qquad H_a: \text{at least one } \beta_j \neq 0\]

Under \(H_0\), the model reduces to \(\hat{Y}_i = \bar{Y}\) — no predictors matter. The test statistic is:

\[F^* = \frac{\text{MSR}}{\text{MSE}} = \frac{\text{SSR}/(p-1)}{\text{SSE}/(n-p)}\]

Under \(H_0\): No predictor explains \(Y\), so MSR and MSE both estimate \(\sigma^2\) — the ratio \(F^* \approx 1\). More precisely:

\[F^* \sim F(p-1,\; n-p) \qquad \text{when } H_0 \text{ is true}\]

When \(H_0\) is false: At least one predictor creates real signal — the \(\hat{Y}_i\) spread out meaningfully, pushing SSR (and MSR) up. MSE stays the same size (it only captures noise), so \(F^* \gg 1\). Large \(F^*\) is evidence against \(H_0\).

SLR vs. MLR F-test: In SLR (\(p = 2\)), \(H_0: \beta_1 = 0\) tests a single slope. In MLR, \(H_0\) constrains all \(p - 1\) slopes simultaneously. It is a joint test: rejecting it only tells you some predictor matters, not which one.

Decision Rule and Connection to SLR

Decision rule at significance level \(\alpha\):

\[\text{Reject } H_0 \text{ if } F^* > F(1 - \alpha;\; p - 1,\; n - p)\]

The critical value \(F(1-\alpha;\, p-1,\, n-p)\) is from an \(F\)-table or qf(1-alpha, p-1, n-p) in R.

Connection to SLR: In SLR (\(p = 2\)), the F-test has \(\text{df}(1,\, n-2)\) and \(F^* = (t^*)^2\) exactly — squaring the \(t\)-statistic for \(H_0: \beta_1 = 0\) gives the \(F\)-statistic. This is a special case of the same test.

Note: Rejecting \(H_0\) tells us at least one \(\beta_j\) matters, but not which ones. That requires the individual inference tools we’ll cover next lecture.

\(R^2\) and Adjusted \(R^2\)

\(R^2\) in Multiple Regression

The coefficient of determination measures the proportion of total variation in \(Y\) explained by the model:

\[R^2 = \frac{\text{SSR}}{\text{SSTO}} = 1 - \frac{\text{SSE}}{\text{SSTO}}\]

  • \(R^2 \in [0, 1]\) — same as in SLR
  • \(R^2 = 0\): predictors explain nothing (\(\hat{Y}_i = \bar{Y}\) for all \(i\))
  • \(R^2 = 1\): perfect fit, all residuals are zero

Warning: \(R^2\) never decreases when you add a predictor, even a completely irrelevant one. This makes \(R^2\) an unreliable tool for comparing models with different numbers of predictors.

Why \(R^2\) Always Increases

Adding a predictor gives the model more flexibility. Even a random noise predictor with no true relationship to \(Y\) will slightly reduce SSE by chance, increasing \(R^2\).

A thought experiment:

Suppose you add 50 random noise predictors to a model — each completely unrelated to \(Y\). What happens to \(R^2\)?

\(R^2\) increases each time and can approach 1 even though the model is worthless. This is overfitting: the model memorizes random variation in the sample rather than capturing the true signal.

We need a measure that penalizes for adding predictors that don’t truly help.

Adjusted \(R^2\)

The adjusted \(R^2\) accounts for model size by using mean squares instead of raw sums of squares:

\[R^2_{\text{adj}} = 1 - \frac{\text{MSE}}{\text{MSTO}} = 1 - \frac{\text{SSE}/(n-p)}{\text{SSTO}/(n-1)}\]

Equivalently: \(R^2_{\text{adj}} = 1 - (1 - R^2)\dfrac{n-1}{n-p}\)

Property \(R^2\) \(R^2_{\text{adj}}\)
Range \([0, 1]\) Can be negative
Adding a useless predictor Always increases Decreases (MSE increases)
Best use Describing a fixed model Comparing models with different \(p\)

Practice: ANOVA for Multiple Regression

A study models exam score (\(Y\), out of 100) using hours studied (\(X_1\)) and prior GPA (\(X_2\)), \(n = 25\) students, \(p = 3\).

\(\text{SSTO} = 2400, \quad \text{SSE} = 480, \quad F(0.95;\; 2,\; 22) = 3.44\)

(a) Compute SSR and \(R^2\). Interpret \(R^2\) in context.


(b) Complete the ANOVA table (df, SS, MS, \(F^*\)).


(c) Test \(H_0: \beta_1 = \beta_2 = 0\) at \(\alpha = 0.05\). State your conclusion in context.


(d) Compute MSE. What does it estimate, and what are its units?

Practice: Solution

(a)

\[\text{SSR} = \text{SSTO} - \text{SSE} = 2400 - 480 = 1920\]

\[R^2 = \frac{\text{SSR}}{\text{SSTO}} = \frac{1920}{2400} = 0.80\]

Hours studied and prior GPA together explain 80% of the variability in exam scores.

(b) With \(n = 25\), \(p = 3\): \(\text{df}(\text{SSR}) = p - 1 = 2\), \(\text{df}(\text{SSE}) = n - p = 22\), \(\text{df}(\text{SSTO}) = n - 1 = 24\).

Source df SS MS \(F^*\)
Regression 2 1920 960 44.0
Error 22 480 21.82
Total 24 2400

(c) Since \(F^* = 44.0 > F(0.95;\; 2,\; 22) = 3.44\), we reject \(H_0\) at \(\alpha = 0.05\). There is sufficient evidence that at least one of hours studied or prior GPA is a significant predictor of exam score.

(d) \(\text{MSE} = 480/22 \approx 21.82\) — an unbiased estimate of \(\sigma^2\), the variance of the errors. Units are (points\(^2\)), so \(\hat\sigma = \sqrt{21.82} \approx 4.67\) points.

Summary

  • ANOVA decomposition: \(\text{SSTO} = \text{SSR} + \text{SSE}\); the definitions of SSR, SSE, and SSTO are identical to SLR — only the degrees of freedom change
  • Degrees of freedom: \(\text{df}(\text{SSR}) = p - 1\); \(\text{df}(\text{SSE}) = n - p\); \(\text{df}(\text{SSTO}) = n - 1\); each predictor costs one df from the error
  • MSE \(= \text{SSE}/(n-p)\) is an unbiased estimator of \(\sigma^2\); \(\hat\sigma = \sqrt{\text{MSE}}\) is the residual standard error
  • F-test: \(H_0: \beta_1 = \cdots = \beta_{p-1} = 0\); \(F^* = \text{MSR}/\text{MSE} \sim F(p-1, n-p)\) under \(H_0\); reject when \(F^*\) exceeds the upper-\(\alpha\) quantile
  • \(R^2\) \(= \text{SSR}/\text{SSTO}\): proportion of variation explained; always increases when predictors are added — cannot be used to compare models of different sizes
  • Adjusted \(R^2\) \(= 1 - \text{MSE}/\text{MSTO}\): penalizes for adding predictors; increases only if the new predictor reduces MSE
  • In R: anova(fit) gives sequential SS for each predictor plus SSE; summary(fit) gives \(\hat\sigma\), \(R^2\), \(R^2_{\text{adj}}\), and the overall \(F\)-test
